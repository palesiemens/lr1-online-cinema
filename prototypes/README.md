# Прототип пользовательского интерфейса

Откройте `index.html` в современном браузере. Прототип демонстрирует главную страницу онлайн-кинотеатра LUMEN: навигацию, продолжение просмотра, каталог, поиск, фильтр по жанрам и диалог карточки фильма. Все действия демонстрационные: рабочий интерфейс должен обращаться к `CinemaService` через API.
